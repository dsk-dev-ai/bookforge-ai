# Project Specification

> Vision, scope, constraints, and architecture overview.

---

## Vision

BookForge AI is a production-grade platform that transforms a technical book specification into a publication-ready PDF and EPUB through an automated pipeline of research, writing, review, diagramming, and rendering.

## Scope

End-to-end technical eBook creation: specification → research → writing → review → diagrams → markdown → PDF/EPUB.

## Supported Topics

AI, ML, Deep Learning, LLMs, AI Agents, RAG, AI Infrastructure, MLOps, DevOps, Kubernetes, Docker, Cloud, APIs, Databases, Distributed Systems, Cybersecurity, Programming, Software Engineering.

## Architecture

Modular event-driven monolith with 14 subsystems, a pluggable provider architecture, and a 13-stage pipeline.

See `docs/ARCHITECTURE.md` for the complete architecture.
